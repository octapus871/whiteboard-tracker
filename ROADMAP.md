# Roadmap

> **Note:** Every feature listed in this document is **planned and not yet implemented**. Nothing below exists in the current codebase.

## Planned Features

### 1. Dark Mode *(Planned — Not Implemented)*
- Add a dark architectural theme alongside the current warm-paper light theme.
- Support manual toggling and optional system theme detection.
- Preserve high-contrast borders, status accents, and legibility across both Arabic (RTL) and English (LTR) layouts.

### 2. Cloud Backup *(Planned — Not Implemented)*
- Optional encrypted or user-controlled sync/backup of `data.json` to cloud storage or a user-configured remote target.
- Keep the application strictly local-first so offline usage remains the default with zero account requirement.

### 3. AI Client Integration *(Planned — Not Implemented)*
- Optional, decoupled AI client integration (e.g., local Ollama endpoints or user-supplied remote API providers) to assist with breaking tasks into subtasks or summarizing daily progress.
- Opt-in only; no network calls or AI dependencies will be enabled by default.
